Le dictionnaire, les polices et l'interface sont intégrés à l'APK. Les recherches s'effectuent sur des fichiers locaux ; leur contenu n'est pas envoyé sur le réseau.

La version actuelle ne comporte ni serveur, ni API, ni outil d'analyse, ni ressource externe ; elle charge seulement les ressources emballées sous file:///android_asset/. Le trafic en clair est désactivé (usesCleartextTraffic="false").

Stockage local

4. Stockage local et sauvegarde Android

L'application peut conserver un cache WebView ou l'état local de l'interface dans l'espace privé de l'appareil. VisdAR ne peut pas les lire et ils ne sont pas téléversés par l'application.

La sauvegarde automatique Android est activée (allowBackup="true"). Si vous activez Google Backup ou la sauvegarde du fabricant, Android peut sauvegarder les données privées de l'application dans votre propre compte cloud. Ce processus est géré par Android ; VisdAR n'y a aucun accès ni contrôle. Vous pouvez le désactiver dans les réglages système, désinstaller l'app ou effacer ses données.

Offline operation

3. Offline operation and network access

The dictionary, fonts, and interface are packaged in the APK. Searches run on local files; their content is not sent over the network.

About the Internet permission: it is declared for Android WebView compatibility. The current version has no server, API, analytics tool, or external resource URL; it loads only packaged resources at file:///android_asset/. Cleartext traffic is disabled (usesCleartextTraffic="false").

Local storage

4. Local storage and Android backup

The app may retain WebView cache or local interface state in the device's app-private storage. VisdAR cannot read it, and the app does not upload it.

Android Auto Backup is enabled (allowBackup="true"). If you enable Google Backup or an OEM backup service, Android may back up app-private data to your own cloud account. Android manages this process; VisdAR has no access to or control over those backups. You may disable it in system backup settings, uninstall the app, or clear its data.
