Content and search run on the device. Favorites remain only in the WebView’s private local storage. They are not uploaded and there is no cloud sync. You can remove favorites in the app; clearing app data or uninstalling the app deletes all favorites.

Reference links open in the system browser. The browser and destination site then process the connection, IP address, and browsing history under their own policies. VisdAR does not receive this information.

This page is hosted on GitHub Pages. When you visit it, GitHub may process IP addresses, logs, and necessary technical data under its General Privacy Statement. This applies to the website visit and does not change the offline app’s no-collection practice.

4. Children, rights, and security

The app is suitable for educational use and collects no personal data from children or adults. Because VisdAR has no server-side user records, there is no remote personal profile to access, correct, export, or delete. Local favorites can be removed as described above.

5. Sources, licenses, and editorial scope

Some lexical data is based on CFDICT (David Houstin, Chine Informations, and contributors). The relevant adapted data is available under CC BY-SA 3.0, which permits commercial use and adaptation with attribution, a change notice, and share-alike licensing for adaptations.

Taiwan’s Ministry of Education idiom dictionary is used only to check bibliography and source references. Its CC BY-ND conditions allow commercial redistribution of unmodified material but prohibit derivatives and simplified-character conversion. The app does not bundle, translate, or adapt its modern dictionary entries. Names of classical works and basic facts are kept distinct from stories, examples, and French wording written for this project.

The current release is a curated set of 100 teaching entries. It is not an exhaustive or textbook-certified inventory of all idioms studied from Chinese primary through junior-secondary school. Screenshots document terms shown on the capture date; the complete license texts control.
