  • 手写识别、拼音、法语释义、词例和笔顺数据均随 APK 静态打包，在本机离线处理。

3. Storage, backup, and links

  • Recognition, pronunciations, dictionary content, examples, and stroke order are bundled in the APK and processed locally.
  • Handwriting, recognition history, and lookups are not saved; clearing the square removes strokes from memory.
  • The WebView can use local storage, but this app does not write user content to it.

Android backup

android:allowBackup="true" enables Android’s optional system backup. If you enable it, the operating system may back up private settings to your account; VisdAR cannot read or control that backup.

External links

The VisdAR website link is opened by the system browser only after you choose it. Any processing on that website is governed by its own policy.

4. SDKs, advertising, and bundled resources

No advertising, analytics, payment, sign-in, or crash-reporting SDK is embedded. HanziLookupJS, Make Me a Hanzi, CFDICT, Complete HSK Vocabulary, and LXGW WenKai GB are offline resources distributed with the APK; they receive no user data while the app is used.
