# Binome · verified font licence evidence

The Binome Android bundle includes `LXGWWenKai-Regular.ttf` and the accompanying `OFL.txt` under `dist/fonts/`. The font is LXGW WenKai, licensed under the SIL Open Font License 1.1. That license permits bundling and commercial use with software subject to its conditions, including retaining the copyright notice and licence; it does not permit selling the font by itself.

- `lxgw-wenkai-ofl-github-2026-10-11.jpg`: screenshot of the [font author's OFL.txt page](https://github.com/lxgw/LxgwWenKai/blob/main/OFL.txt), captured on 11 October 2026. GitHub's licence summary visibly lists “Commercial use”. The live upstream page may change after capture.
- `OFL.txt`: the licence text that accompanies the font file in this project's Android bundle.

This evidence concerns the font only. It is **not** a licence certificate for the game's images, sound, text dataset, Microsoft Speech SDK, or any other component. Original project artwork and third-party components require separate provenance checks.
